PET-94 Web 包实测：页面控制台原样记录（证据，不是期望值）
怎么来的：tools/web_check.ps1 —— python -m http.server 起普通静态服务（不发 COOP/COEP），
          无头 Edge 打开 index.html，把页面 console.* 原样转出来，此处按行去重。
同目录的旁证：web_boot_failure.png —— 这一屏长什么样（画布真的在画，字显示成方框）。
读法：引擎起来了（下面第 1~3 行），WebGL 2.0 也通了，但游戏**自己拒绝开局**（第 4 行）——
      界面字体在浏览器里显示不了中文，BootScreen 于是停在失败屏。
      不是资源没下载下来、也不是没起来，是运行期的一条判定把这一局挡在门外。
复现：powershell -File tools/web_check.ps1 -Root <仓库根目录>
