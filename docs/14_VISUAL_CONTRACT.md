## 1. 坐标、组件与字号的统一契约

| 项目 | 960×540 逻辑值 | 1920×1080 设备值 |

| 书本投影：偏移 / 模糊半径 / alpha | (4,8) / 8 / 0.28 | (8,16) / 16 / 0.28 |

所有 rect = `(x,y,w,h)`，左上原点、右/下半开区间；表中「间距」按边到边计算。描边在 rect 内侧，额外状态轮廓单独记账；子元素均为屏幕绝对坐标，卡内构成除外。所有 UI 最终轮廓落**整数逻辑像素**；模型的自由拖动坐标仍保留小数，**不能**以绘制对齐为由量化位置。下文 `R/S` 指圆角半径/基础描边宽，0 表示没有。

文字的实际字体 ascent+descent 必须 ≤ 表列行高；Label 使用既定行框，不通过切换语言自动增大父控件。不以「字数×字号」猜英文宽度。两种语言实际 shaping 后宽度须 ≤ 内容区；说明允许按指定行数换行，按钮不省略、不缩字号。字体不合格时**报告该字体度量**，不暗中放大控件或换字体。开启字体抗锯齿 ≠ 对整屏做非整数缩放。
